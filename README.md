# Forest-Creator

## A short description:

## It allows a set dressor to quickly generate and color a simple forest created with 
## simple modeling, the user can decide on different colors for the mushrooms, rocks
## trees and even the leaves. The user can also decide on how the forest is generated
## the user has multiple options like generation in the center, edges, uniform or random. 
## Additionally, the user can decide on the spacing of the objects, how many there are, if there
## is collision or not, height variation, and rotation.
